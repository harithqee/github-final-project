# Code of Conduct
## Our Pledge
We welcome participation by everyone and commit to a respectful, harassment-free community.
## Our Standards
Be considerate, give constructive feedback, and respect differing experiences. Harassment, personal attacks, and sharing private information without consent are unacceptable.
## Enforcement Responsibilities
Maintainers explain and apply these standards fairly.
## Scope
This code applies in project spaces and when representing the project publicly.
## Enforcement
Report concerns privately using GitHub’s reporting tools. Maintainers will protect reporters’ privacy when reviewing reports.
## Enforcement Guidelines
Depending on severity and repetition, responses may include a correction, warning, temporary ban, or permanent ban.
